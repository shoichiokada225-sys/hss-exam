問1スノコ床（スラット床）の主な目的として最も正確なものはどれですか？飼養環境・施設
  1. ①糞尿をスノコの隙間から下に落とし、床面を清潔に保つ
  2. ②豚の蹄（ひづめ）の伸びすぎを防止し、適度に削る
  3. ③床面の温度を上げて保温効果を高める
  4. ④糞尿と飼料の食べこぼしを分離して回収する
問2「経済豚と幸せの創造」において、推奨されている行動はどれでしょうか経営理念・行動規範
  1. ①効率のみを優先した飼育を行う
  2. ②夏場・冬場対策を、暑さや寒さが本格化してから行う
  3. ③豚の行動や状態を日々観察し、ストレス低減を意識した管理を行う
  4. ④精肉の歩留まりを気にせずカットを実施する
問3「里子（さとご）」とは何ですか？繁殖・分娩
  1. ①産子数が多い母豚の子豚を、余裕のある他の母豚に預けること
  2. ②異なる品種の豚を交配させること
  3. ③複数の豚舎で豚をローテーションさせること
  4. ④子豚を別農場で育てること
問4「責任感とチームの絆」において、厳に慎むべき思考・行動はどれでしょうか経営理念・行動規範
  1. ①トラブルを部署横断で共有し、緊急時はチームで対応する
  2. ②忙しい仲間を自然にフォローし、全体最適を意識する
  3. ③休日の前日はメモを作成し、翌日の後任に申し送る
  4. ④悪評、陰口を言って他人を貶めたり、事実無根の話を連発する
問5ヒラノが経営理念において使命とする「幸せの連鎖」として正しい組み合わせはどれでしょうか経営理念・行動規範

  4. ④豚が幸せに育ち、育てた人が誇りを持ち、食べる人が喜ぶ
