# HSS認定試験 試験官カード（当日手持ち用・A4 1枚）

## 開始前（会場で）
- [ ] 自分の端末でアプリ起動→ホームが最新版か確認
- [ ] スプレッドシート3タブを開き画面に出す
- [ ] 名簿の正式表記一覧を掲示
- [ ] 受験者端末: 充電・自動時刻ON・（共有機のみ）電波確認

## 開始時
- [ ] PWを板書して開始宣言（終了後に板書を消す）
- [ ] 全員のタイマーが動いたことを目視

## 試験中（巡回）
- [ ] **2窓・画面分割・別端末はアプリでは検知できない→目視が唯一の防衛**
- [ ] 琥珀色バナー（離脱記録）が出た端末: 座席と時刻をメモ
- [ ] シートを時々リロード→終了者数と行数が合っていくか

## 終了時
- [ ] 「✅ 送信されました」まで閉じさせない
- [ ] ⚠表示の端末: 閉じさせずスタッフへ→電波の良い場所でアプリを開き直すと自動再送

## トラブル早見表
| 症状 | 対応 |
|---|---|
| 画面が消えた/リロードされた | アプリを開き直す→「再開する」ボタン。回答は残っている |
| 端末が完全に故障 | 代替端末で最初から。氏名を「氏名(再)」で入力（シート側は重複列でも検知される） |
| 時間切れの表示のまま固まった | そのまま待つ（自動送信中・最大3分）。3分経っても変化なければ⚠扱い |
| 全員送信できない（GAS障害） | 試験はそのまま実施してよい。後で各端末でアプリを開けば自動再送 |
| 受験者が時計をいじった形跡 | シートの離脱内訳に「⚠時刻逆行」が出る。目視メモと突合 |
