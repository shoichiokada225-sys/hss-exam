# GAS 再デプロイ手順（150人同時対応・重要）

`gas/Code.gs` を更新しました。**反映には社長による再デプロイが必要**です（私はGASをデプロイできません）。

## なぜ必要か
個人Gmailのメール送信は **100通/日が上限**。従来の「1人1通メール」方式では150人で破綻するため、
**結果はスプレッドシートに記録し、メールは1日1回のサマリーだけ**に変更しました。

---

## 手順（5分）

### 1. コードを貼り替え
1. https://script.google.com を開き、HSS試験のプロジェクトを開く
2. `Code.gs` の中身を全削除し、リポジトリの `gas/Code.gs` を全文コピペして保存（Ctrl+S）

### 2. 初回だけ実行してスプレッドシートを自動作成
1. 関数選択で `doGet` を選び「実行」→ 権限承認を求められたら許可
2. 「実行ログ」に出る「記録用スプレッドシートを作成: https://...」のURLを開いて確認
   - 以後、全結果はこのシート（タブ: `本試験結果` / `回答詳細` / `受験意志確認`）に記録されます

### 3. 再デプロイ（URLを変えないこと）
1. 右上「デプロイ」→「**デプロイを管理**」
2. 既存のウェブアプリの **鉛筆アイコン** → バージョン「**新バージョン**」を選択 → デプロイ
   - ※「新しいデプロイ」で作り直すとURLが変わり `config.js` の修正が必要になるので避ける
   - 設定確認: 実行するユーザー=**自分** / アクセスできるユーザー=**全員**

### 4. 日次サマリーメールのトリガー設定
1. 左メニュー「**トリガー**（時計アイコン）」→「トリガーを追加」
2. 関数: `sendDailySummary` / イベントのソース: **時間主導型** / **日付ベースのタイマー** / **午後8時〜9時** など
3. 保存 → 毎日その時間に「本日の受験者数・合格/不合格・一覧」が `so@oikk.co.jp` に1通届きます

---

## 動作の仕組み（堅牢化のポイント）
- **記録の正本＝スプレッドシート**（メール上限の影響を受けない）
- **LockService** で同時書き込みを直列化（行欠落なし）
- **submissionId による重複排除**（再送しても二重記録なし）
- クライアントは **JSONP で「記録されたか」を確認 → 未記録なら自動再送**（取りこぼしゼロ）
- 送信前に **0〜15秒のジッター** で一斉終了のバーストを平準化
- 端末側は **localStorage に結果を保持**し、失敗時や再アクセス時に自動再送

## テスト方法
1. 本番URLで1人分受験 → 結果画面が「自動送信しました」になればOK
2. スプレッドシートの `本試験結果` に行が増えていることを確認
3. `sendDailySummary` を手動実行 → サマリーメールが届くか確認
